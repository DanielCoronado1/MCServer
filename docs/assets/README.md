# Recursos de la portada

[← Volver a DolfinServer](../../README.md)

`dolfin-cover.png` es la cabecera original de DolfinServer, generada con la herramienta integrada de generación de imágenes de Codex. Se revisó visualmente antes de incorporarla. La ilustración es identidad visual del proyecto; no es una captura del servidor.

## Prompt de generación

El prompt se conserva en su idioma original para poder recrear la imagen:

```text
Use case: stylized-concept
Asset type: wide GitHub repository README cover for DolfinServer, a Spanish-language Minecraft Fabric server with custom creepers.
Primary request: Create a beautiful polished voxel art cover, wide landscape 3:1 composition. A friendly block-built turquoise dolphin leaps above a luminous river through a small lush blocky Minecraft-inspired landscape, with stepped grassy cliffs, a tiny cabin, pine trees, and an understated green creeper watching from shore. Night transitioning into dawn, dark navy sky, cyan water, warm amber window light. Crafted game key art, clean chunky voxel geometry, atmospheric depth, restrained bloom. Make the dolphin the recognizable visual focal point. Composition should read clearly at 900px wide.
Text (verbatim): "DOLFIN" in large crisp custom block lettering centered in the upper sky, with "SERVER" smaller directly underneath. No other text.
Constraints: no UI, no badges, no watermarks, no real-world logos. Cohesive premium game community identity. Full bleed opaque background.
```
